Сюда кладутся девять файлов GLB с такими именами:

| Файл | Что это |
|---|---|
| `model.glb` | персонаж со скелетом и текстурами |
| `idle.glb` | ожидание, цикл |
| `run.glb` | бег на месте, цикл |
| `jump.glb` | прыжок |
| `punch.glb` | удар рукой |
| `kick.glb` | удар ногой |
| `roll.glb` | кувырок или нырок с перекатом |
| `hit.glb` | реакция на попадание |
| `win.glb` | радость в конце раунда, цикл |

Имена костей в клипах должны совпадать со скелетом `model.glb`.

Нет подходящего клипа — положите на его место копию близкого: `kick.glb` = `punch.glb`, `roll.glb` = `jump.glb`.
Игра заработает, только кувырок будет выглядеть как прыжок, а удар ногой как удар рукой.

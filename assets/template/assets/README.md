Сюда кладутся семь файлов GLB с такими именами:

| Файл | Что это |
|---|---|
| `model.glb` | персонаж со скелетом и текстурами |
| `idle.glb` | ожидание, цикл |
| `run.glb` | бег на месте, цикл |
| `jump.glb` | прыжок |
| `punch.glb` | удар |
| `hit.glb` | реакция на попадание |
| `win.glb` | радость в конце раунда, цикл |

Имена костей в клипах должны совпадать со скелетом `model.glb`.

# glb-browser-game

Скилл для Claude Code: играбельная 3D-игра в браузере из вашего персонажа с риггингом, для компьютера и телефона. На выходе один HTML-файл, который открывается двойным кликом.

Что умеет:

- проверить модель и клипы анимации: скелет, совпадение костей, проблемные материалы;
- построить раскадровку клипов и по ней настроить тайминги ударов, прыжка и кувырка;
- собрать игру от третьего лица на Three.js: бег, спринт, прыжок, удар рукой или ногой (выбор случайный), кувырок-уворот, камера со столкновениями, город, предметы, враги, сердца, частицы, звук, пауза и итоги;
- управление с телефона: плавающий джойстик, свайп камеры, кнопки, запрет масштабирования страницы;
- убрать чёрные пятна у автоматически созданных моделей;
- проверить игру настоящими клавишами, кликами и касаниями в headless Chrome: `npm test` и `npm run test:touch`.

Порядок работы — в [SKILL.md](SKILL.md). Запуск нейрорендера Matrix-Game 4.0 на видеокарте с 24 ГБ — в [references/matrix-game-24gb.md](references/matrix-game-24gb.md).

## Установка

```bash
git clone https://github.com/ircitdev/glb-browser-game-skill ~/.claude/skills/glb-browser-game
```

После этого достаточно попросить Claude Code, например: «сделай игру с моим персонажем из model.glb».

Нужны Node.js 22 или новее, Python и Google Chrome. Для другого расположения Chrome задайте переменную `CHROME`.

## Важно

- Модели и клипы анимации в репозиторий не входят, нужны свои: персонаж с риггингом и восемь клипов с теми же именами костей (ожидание, бег, прыжок, удар рукой, удар ногой, кувырок, попадание, радость). Если подходящего клипа нет, можно подставить копию близкого, подробности в `assets/template/assets/README.md`.
- Лицо реального человека используйте только с его согласия.
- Касания проверены только в эмуляции Chrome. На живых телефонах расположение кнопок и чувствительность камеры могут потребовать подстройки. На iPhone нет полноэкранного режима и вибрации.
- Придумывайте свою игру: скилл не для того, чтобы воспроизводить чужие названия, героев и уровни.

# glb-browser-game

Скилл для Claude Code: играбельная 3D-игра в браузере из вашего персонажа с риггингом. На выходе один HTML-файл, который открывается двойным кликом.

Что умеет:

- проверить модель и клипы анимации: скелет, совпадение костей, проблемные материалы;
- построить раскадровку клипов и по ней настроить тайминги удара и прыжка;
- собрать игру от третьего лица на Three.js: бег, ускорение, прыжок, удар, камера со столкновениями, город, предметы, враги, частицы, звук, пауза и итоги;
- убрать чёрные пятна у автоматически созданных моделей;
- проверить игру настоящими клавишами и кликами в headless Chrome.

Порядок работы — в [SKILL.md](SKILL.md). Запуск нейрорендера Matrix-Game 4.0 на видеокарте с 24 ГБ — в [references/matrix-game-24gb.md](references/matrix-game-24gb.md).

## Установка

```bash
git clone https://github.com/ircitdev/glb-browser-game-skill ~/.claude/skills/glb-browser-game
```

После этого достаточно попросить Claude Code, например: «сделай игру с моим персонажем из model.glb».

Нужны Node.js 22 или новее, Python и Google Chrome. Для другого расположения Chrome задайте переменную `CHROME`.

## Важно

- Модели и клипы анимации в репозиторий не входят, нужны свои: персонаж с риггингом и шесть клипов с теми же именами костей.
- Лицо реального человека используйте только с его согласия.
- Управление рассчитано на клавиатуру и мышь, сенсорного в шаблоне нет.
- Придумывайте свою игру: скилл не для того, чтобы воспроизводить чужие названия, героев и уровни.

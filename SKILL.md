# Браузерная игра из своего персонажа

Цель — страница, в которую можно сыграть двойным кликом: один HTML-файл без сервера, с вашей моделью и её анимациями. Шаблон уже умеет бег, ускорение, прыжок, удар, камеру со столкновениями, врагов, предметы, частицы, звук, паузу и экран итогов, так что работа сводится к подгонке под модель и к своей механике.

Дальше `$SKILL` — папка этого скилла, `$GAME` — новая пустая папка проекта. Модель и клипы — файлы пользователя: лицо реального человека берите только с его согласия.

## 1. Паспорт модели

```bash
python -I "$SKILL/scripts/glbinfo.py" model.glb clip1.glb clip2.glb
```

Смотрите три вещи. Есть ли скелет: без него анимировать нечего, и модель сначала надо заригать. Строка «нет в скелете» у каждого клипа должна показывать 0: иначе клип не привяжется к костям, и персонаж застынет. Сколько материалов с картами нормалей и металла: у автоматических моделей они дают чёрные пятна при свете, шаблон снимает их при загрузке.

Нужны шесть клипов: ожидание, бег на месте, прыжок, удар, попадание, радость. Если какого-то нет, спросите пользователя или возьмите ближайший по смыслу.

## 2. Развернуть шаблон

```bash
cp -r "$SKILL/assets/template/." "$GAME/" && cd "$GAME" && mkdir -p dist
npm i
```

Положите файлы в `assets/` под именами из `assets/README.md`.

## 3. Посмотреть раскадровку

```bash
npm run sheet     # dist/sheet.png
```

Откройте картинку и прочитайте её: на глаз тайминги не угадать, а клипы часто устроены не так, как называются.

- **Верхний ряд** — поза покоя с десяти сторон, первый кадр снят с +Z. Найдите, в каком столбце видно лицо, и задайте `modelRotationY` в `src/config.js`: лицо в первом кадре — `0`, Tripo смотрит вдоль +X — `-Math.PI / 2`.
- **Удар.** Десять кадров идут равными долями длины клипа. Найдите начало замаха и пик, подберите `start` и `speed` так, чтобы пик пришёлся примерно на 0,2 с после нажатия. Если меняете `speed`, поправьте `player.punch` и `player.cool` в `punch()`.
- **Прыжок.** В клипе бывает несколько подскоков подряд, тогда берите только первый: `speed` подбирается так, чтобы он занял примерно 0,75 с, это время в воздухе.

## 4. Сделать игру своей

В `src/config.js` — название, бренд, цвет, длина раунда, рост и тексты. Механику меняйте в `src/main.js`: город собирается в разделе «Город», предметы и враги идут отдельными блоками, правила — в `collect`, `punch`, `damage`.

Придумайте свою идею, название и образы. Жанр и приёмы использовать можно, а воспроизводить конкретную чужую игру — её название, героев, уровни и внешний вид — нельзя.

Клавиши читайте через `e.code`, а не `e.key`: на русской раскладке `e.key` вернёт «ц» вместо «w», и игра перестанет слушаться.

## 5. Собрать и проверить

```bash
npm run build     # dist/index.html
npm test          # настоящие клавиши и клики в headless Chrome, скриншоты в dist/shots
```

Тест проверяет бег, направление от камеры, ускорение, прыжок, сбор предмета, удар, урон, конец раунда, повтор и отсутствие ошибок в консоли. Если поменяли правила, поправьте `tools/test.mjs`, иначе он будет проверять старую игру. Адрес на проде проверяется так же: `GAME_URL=https://... npm test`.

Прошедший тест не значит, что игра хорошо выглядит: откройте скриншоты и посмотрите на меню, бег и удар. В headless нельзя проверить захват мыши и звук, об этом скажите пользователю прямо, и пусть попробует сам.

## 6. Отдать

`dist/index.html` работает прямо с диска: скрипт встроен, модели лежат внутри как data-URL. Обычно это 8–10 МБ, сервер сжимает примерно до 5 МБ. Подойдёт любой статический хостинг. Не забудьте сказать, что нужны клавиатура и мышь: сенсорного управления в шаблоне нет.

## Подводные камни

| Что видно | Причина | Что сделать |
|---|---|---|
| Чёрные пятна на лице и одежде | карты нормалей и металла автоматической модели | снимаются при загрузке, в `loadAll` |
| Модель не загружается, ошибка про meshopt | GLB сжат gltfpack | `setMeshoptDecoder`, уже подключён |
| Персонаж бежит спиной вперёд | неверный `modelRotationY` | верхний ряд раскадровки |
| Персонаж пропадает у края кадра | у скиннинга неверные границы | `frustumCulled = false`, уже стоит |
| Цикл бега дёргается или уезжает | накопленный сдвиг таза | `cleanClip` убирает линейный дрейф |
| Модель раздувается во время клипа | scale-дорожки клипа | `cleanClip` их удаляет |
| После `Esc` игра встала на паузу | браузер снял захват курсора | так задумано: `pointerlockchange` ведёт в меню |
| Кнопки зависают после смены окна | клавиша отпущена вне окна | по `blur` ввод очищается и включается пауза |
